# Local models

This folder is for standalone GGUF files when you select **GGUF file (llama.cpp)** in the StoryForge sidebar. GGUF model files are excluded from Git/ZIP because of their size.

If you already use Ollama, you do not need to copy its internal model blobs here. Select **Ollama (recommended if installed)** and type an installed model tag such as `gemma3:4b`.
